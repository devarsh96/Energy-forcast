Fuel columns

Times are Toronto local, by the start of the hour. Output is the hourly average in MW (equal to MWh for the hour). Intensity and emissions count only fuels with an emission factor. Select any column header to sort. Up to 100 days at a time.

Data sources

All data comes from the IESO public reports site. Emission factors: IPCC AR5 Working Group III (2014), Annex III, lifecycle median values.

Public API

Read-only JSON, no key needed, open to other sites (CORS). Dates are Toronto local, in YYYY-MM-DD form. Data is served from this app's cache and refreshes every 5 minutes.
