How this is worked out

  • "Right now" assumes the task starts this hour, using the latest IESO hour's intensity for the first hour and the forecast after that.
  • The best time is the run of consecutive hours, within the next 24, with the lowest average forecast intensity.
  • Energy is spread evenly over the run time. CO₂ = kWh in each hour × that hour's g CO₂e/kWh.
  • The driving comparison uses about 190 g CO₂ per km for an average gasoline car (a rough assumption, for scale only).
